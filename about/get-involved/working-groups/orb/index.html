ORB

The ORB Working Group maintains the Open Repository Browser (ORB), an open source toolkit for finding and exploring the open source software a university produces. ORB started inside the Network’s Discovery Working Group and is now an open source project in its own right, with contributors from outside UC.

Hosts: Juanita Gomez (ORB maintainer) and Virginia Scarlett

Membership: The community call is open to anyone. Voting membership of the working group is set out in ORB’s governance document.

What this group does¶

The group looks after the upstream ORB project: architecture, features, data infrastructure, and code review. ORB is a small family of repositories:

  • repofinder: identifies and analyzes repositories affiliated with a university, using GitHub metadata and contributor analysis

  • repoexplorer: the interactive dashboard for exploring repositories, contributors, and activity, built in Python with Shiny

  • orb-showcase: a web application for presenting the data repofinder collects

  • orb-community: governance, code of conduct, contributing guide, and meeting summaries shared across the project

For background on the approach, see the ORB paper.

ORB and Discovery¶

The two groups are related but distinct:

  • The ORB Working Group maintains the open source toolkit. It is developer-focused and open to anyone, at UC or not.

  • The Discovery Working Group is the UC OSPO Network’s group for mapping UC open source. It runs the UC instance of ORB, alongside the project showcase and the UC-wide survey.

Meetings¶

The group holds an open community call on the first Tuesday of each month, 1–2pm Pacific. Details and a calendar link are on the events page. The call is aimed at people who want to work on the code, and users who want to follow along are welcome too.

The call isn’t recorded. After each one the group publishes a short written summary in the orb-community repository.

Join¶

Come to a community call, join our ORB Slack channelor start with the contributing guide. Contributor onboarding documentation is still being written, so if you want to help and aren’t sure where to start, let us know in the Slack channel or on a call!
